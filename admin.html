Buat Bucket Storage

Kalau upload error "Bucket not found":
  1. Supabase → Storage → New Bucket → nama media → centang Public.
  2. Jalankan policy storage di SQL Editor.
  3. Refresh admin, klik Cek Bucket.

Buat User Admin

Supabase → Authentication → Users → Add User. Gunakan email & password itu untuk login di sini.
